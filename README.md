# Currículo Online - Breno

Este projeto é um currículo profissional online desenvolvido como Trabalho Prático para a disciplina de Desenvolvimento Web. O objetivo é exercitar a criação de páginas web utilizando as principais tecnologias do mercado.

🔗 *Repositório do Projeto:* [https://github.com/Brenolopes03/Trabalho](https://github.com/Brenolopes03/Trabalho)

## 🛠️ Tecnologias Utilizadas
* *HTML5:* Estrutura e semântica da página web.
* *CSS3:* Estilização, layout e responsividade.
* *JavaScript:* Interações de front-end (validação de formulário e rolagem suave).
* *PHP:* Processamento e simulação de envio de dados no servidor.

## 📂 Estrutura do Projeto
/meu-curriculo
 ├── index.html     # Estrutura principal
 ├── style.css      # Estilização
 ├── script.js      # Scripts interativos
 ├── contato.php    # Processamento de formulário (Back-end)
 ├── /img           # Imagens de perfil e assets
 └── README.md      # Instruções do projeto
